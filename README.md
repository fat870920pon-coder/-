# 月下餐飲集團 ➔ 文中會計系統智慧傳票與對帳查帳中心

本工具專為多餐飲事業體（月宮、隨意小吃等）量身打造，具備「營業傳票產生」、「玉山銀行自動勾稽沖銷」、「手續費發票 OCR 辨識」、「未存款異常穿透追蹤」與「瀏覽器互動對帳月曆看板」等完整智慧會計功能。

---

## ⚡ 核心功能特色

1. **一鍵全自動多店營收傳票**：自動抓取 Google 試算表各店營業數據，產出完全符合文中 42 欄官方格式之合併 Excel。
2. **玉山銀行智慧沖銷與日期回溯**：
   - 自動將玉山銀行單筆存款精準對齊門市營業日（包含隔日存入、週末連假多日累計存入）。
   - 自動計算 Uber Eats 週結算區間、LINE Pay T-2 營業日、Foodpanda 半月款。
   - **現金短溢自動調節**：若存款與 POS 有零星尾差，自動補上 `7112 現金短溢` 分錄，借貸 100% 平衡。
3. **未存款／逾期異常穿透追蹤（Sheet 3）**：
   - 精確抓出哪一家店、哪一天營業額、多少金額、已過幾天還沒存入銀行。
   - 自動分級：🚨 嚴重逾期（超過 5 天）、⚠️ 一般逾期（3~5 天）、⏳ 近期交班（1~2 天）。
4. **一鍵可視化查帳月曆看板（HTML 儀表板）**：
   - 點兩下立即在 Safari / Chrome 開啟互動儀表板。
   - 支援切換「集團總覽」、「月宮」、「隨意小吃」。
   - 月曆綠燈（已存入）、紅燈（未存入），一眼看透全月資金流向。
5. **手續費發票自動辨識匯入**：
   - 支援將手續費發票（PDF、Excel、CSV、TXT）丟入 `invoices/` 資料夾，自動 OCR 辨識字軌號碼、未稅金額、5% 營業稅並產出文中 42 欄傳票。

---

## 🚀 常用一鍵快捷指令（Mac 桌面點兩下）

* 📄 **`一鍵產生傳票.command`** ➔ 產生門市每日營業收入傳票（全部合併單一 Excel）。
* 🏦 **`一鍵對帳_玉山銀行.command`** ➔ 勾稽玉山銀行入帳明細，回填 Google 試算表並產出沖銷傳票。
* 🧾 **`一鍵辨識發票產生傳票.command`** ➔ 偵測 `invoices/` 中的手續費發票並產出文中傳票。
* 📊 **`查看本月對帳差額.command`** ➔ 結算並輸出各通路未清差額與 Sheet 3 異常清單。
* 🌐 **`查看可視化對帳看板.command`** ➔ **一鍵更新並在瀏覽器跳出「互動對帳月曆看板」！**

## 📁 檔案產出說明 (`output/`)

* **`output/文中傳票維護匯入_全部合併_YYYYMM.xlsx`**：每日營收傳票（純日期、@ 自動配號、42 欄官方格式）。
* **`output/文中傳票維護匯入_全部合併_玉山銀行沖銷_YYYYMM.xlsx`**：玉山銀行沖銷傳票（詳細標註所屬款項日與短溢調節）。
* **`output/本月對帳差額與應收餘額表_YYYYMM.xlsx`**：
  - **Sheet 1 (`對帳差額總表`)**：各通路 POS 累計、銀行已沖、發票已沖、目前差額。
  - **Sheet 2 (`玉山單筆沖銷對照`)**：銀行每筆入帳對應哪幾日營業款。
  - **Sheet 3 (`門市未存款與異常追蹤`)**：詳細點名每筆未存營業日、已延遲天數與處置建議。
* **`output/最新對帳看板.html`**：可視化網頁看板，雙擊即開即查。
