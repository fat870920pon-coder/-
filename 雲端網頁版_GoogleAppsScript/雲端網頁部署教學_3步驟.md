# 🌐 月下餐飲集團 · 雲端對帳看板 (Google Apps Script Web App) 部署指南

本方案為 **方案 3：雲端化網頁 (Google Apps Script 原生架構)**。
**特點：**
- 🌟 **24 小時隨開即看**：不需打開 Mac 電腦，不需執行 `.command` 指令。
- 📱 **手機 / 平板 / 電腦全平台支援**：可直接存為 iPhone / Android 主畫面捷徑或加入瀏覽器書籤。
- 🗓️ **支援自選月份**：頂部具備月份下拉選單，可切換 2026-10、2026-09 或任何歷史/未來月份。
- 🏢 **事業體秒切換**：支援「集團合併總覽」、「月宮 (月下餐飲)」、「隨意小吃」。
- 🔍 **穿透式異常追蹤**：逾期未存現金即時預警，點擊「查看月曆」自動定位日期。
- 🏦 **單筆沖銷對照**：即時搜尋玉山銀行各筆存款對應哪幾日營收或跨月累計款。

---

## 🚀 部署 3 步驟（約 2 分鐘完成）

### 第一步：開啟月宮 Google 試算表之 Apps Script
1. 請以瀏覽器開啟 [月宮 POS 試算表](https://docs.google.com/spreadsheets/d/19QdWcBQWVNi-SWvzuWhA9lfZFInbtrbmpNIqINa1DYA/edit)
2. 點擊頂端選單的 **「擴充功能」 (Extensions)** ➔ **「Apps Script」**。
   *(會開啟一個新的 Google Apps Script 程式碼編輯器分頁)*

---

### 第二步：貼上程式碼與網頁範本
1. **貼上後端程式碼 (`Code.gs`)**：
   - 在左側檔案清單中，點開 `程式碼.gs`（或 `Code.gs`）。
   - 將裡面的內容全選刪除，然後開啟本資料夾中的 `Code.gs`，將全部內容複製貼上。
2. **建立前端網頁範本 (`Index.html`)**：
   - 點擊左側檔案清單上方的 **「+」號** ➔ 選擇 **「HTML」**。
   - 輸入名稱為 **`Index`**（大小寫需一致，不用打 `.html`）。
   - 將新建立的 `Index.html` 預設內容全選刪除，開啟本資料夾中的 `Index.html`，將全部內容複製貼上。
3. 點擊上方的 **「儲存專案 (磁碟片圖示 💾)」** 或按 `Cmd + S`。

---

### 第三步：發布部署為網頁應用程式 (Web App)
1. 點擊右上角深藍色的 **「部署」 (Deploy)** ➔ 選擇 **「新增部署」 (New deployment)**。
2. 在左側齒輪 ⚙️ 圖示中確認類型為 **「網頁應用程式」 (Web app)**。
3. 設定選項：
   - **說明**：`月下集團雲端對帳看板`
   - **執行身分 (Execute as)**：選擇 **「我」 (Me)**
   - **誰可以存取 (Who has access)**：選擇 **「所有人」 (Anyone)**（若想限內部 Google 帳號，可選「您的機構中的任何人」）
4. 點擊右下角 **「部署」** 按鈕。
   > 💡 *若首次部署出現「需要授權」提示：點擊「審查權限」➔ 選擇您的 Google 帳號 ➔ 點擊「進階 (Advanced)」➔ 點擊「前往專案 (不安全)」➔ 點擊「允許 (Allow)」即可。*
5. 部署完成後，畫面會顯示 **網頁應用程式網址**（格式如 `https://script.google.com/macros/s/AKfycb.../exec`）：
   - 複製此網址！

---

## 📱 日常使用方式

1. **手機加入主畫面**：
   - 在 iPhone Safari 中開啟該網址 ➔ 點擊下方「分享」按鈕 ➔ 選擇「加入主畫面」，立即變成像 App 一樣的查帳捷徑。
2. **切換月份**：
   - 網頁頂端設有「對帳月份」下拉選單，點選即可秒切換 2026-10、2026-09 等不同月份。
3. **雲端自動同步**：
   - 當您在 Mac 執行文中傳票或對帳時，系統會自動將最新沖銷與勾稽結果同步至試算表的 `【雲端對帳資料庫】` 分頁，雲端網頁隨時保持最新！
   - 即便 Mac 未開機，雲端網頁也內建即時 POS 試算表解析引擎，隨時計算最新營收與存款狀態。
